# Welcome to My_Yelp
***

## Task
Deploy a ReactJS application with GraphQL integration to AWS Amplify, ensuring authentication and cloud hosting are functional. The challenge is configuring AWS Amplify correctly while integrating authentication and GraphQL API.

## Description
This project is a Yelp-like application where users can browse and review businesses. It is built with ReactJS and uses GraphQL for data fetching. The application is hosted on AWS Amplify, which provides authentication, backend API, and cloud hosting.

## Installation
To install and set up the project locally, follow these steps:
$> git clone https://your-repository-link.git
$> cd my-yelp
$> amplify init
$> amplify add auth
$> amplify add api
$> npm install

## Usage
To run the project locally:
$> npm start

To deploy it to AWS Amplify:
$> amplify add hosting
$> amplify publish
